## 已修正问题

| 问题 | 原因 | 修正 |
| --- | --- | --- |
| TTS 等待为 0 时没有第二次尝试 | 重试条件和等待条件混在一起 | 无论等待是否为 0 都重试一次 |
| 损坏词典中断后续文件处理 | 依赖抛出 struct.error 或普通 Exception | 在第三方构造和解码边界转换为带上下文及原异常链的 ValueError |
| 空 MDD 资源误读后续录音 | 依赖将零长度当作块剩余内容 | 根据记录偏移返回真正的空资源 |
| 大写 .MDD 被当成文本 | 依赖根据大小写敏感扩展名判断记录类型 | 根据 MDX/MDD 读取器类型确定文本或二进制 |
| 跨块记录可能截断 | 原读取函数只切取一个解压块 | 读取完整记录区间，检查长度，保留二进制字节 |
| 重复 TTS 循环和统计逻辑 | passage 和例句分别执行 UK/US 任务 | 共用任务执行循环 |
| 模块依赖相互引用 | 词典模块从 app 取分卷发现，TTS 从 extractor 取筛选 | 分卷发现移入 mdict_index，筛选移入 wordlist |
| 重复读取 JSON | 扫描、提取及 TTS 各自重新读取 | 复用本次加载的数据，独立入口仍保留校验 |
| 已有 WAV 提示为 MP3 | 提示使用预期输出名 | 提示实际跳过的已有文件名 |
| 无效覆盖选项及不可达分支 | 旧接口遗留 | 删除覆盖参数及不可达错误返回 |

局部词典资源失败仍允许继续其他口音/词条。未提交 JSON 前发生整体失败时，回滚本次新增词典音频，避免留下音频与旧 IPA 不一致的状态。
